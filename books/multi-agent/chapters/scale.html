Chapter 09

비용 · 지연 · 확장성

멀티에이전트 시스템은 비싸다. 에이전트마다 시스템 프롬프트와 도구 정의를 새로 읽고, 리더가 쓴 지시서를 읽고, 자기 탐색 결과를 쌓고, 요약을 만들고, 리더는 그 요약들을 다시 읽는다. 이 장에서는 토큰이 정확히 어디로 가는지 분해하고, 에이전트를 늘릴 때 처리량이 언제 꺾이는지, 역할마다 어떤 모델을 쓸지, 정해진 예산을 몇 명에게 나눌지를 실험한다.

  • 채팅·단일 에이전트·멀티에이전트의 토큰을 항목별로 분해하고 토큰 배수를 추정할 수 있다.
  • 범용 확장성 법칙(USL)의 σ와 κ로 에이전트 수의 최적점을 계산할 수 있다.
  • 리더와 워커에 서로 다른 모델을 쓰는 모델 계층화의 비용-품질 균형을 따질 수 있다.
  • 고정된 토큰 예산을 몇 명의 워커에게 나눌지 넓이와 깊이의 균형으로 정할 수 있다.

토큰은 어디로 가나

Anthropic은 자사 리서치 시스템을 설명하며, 에이전트는 일반 채팅보다 약 4배, 멀티에이전트 시스템은 약 15배의 토큰을 쓴다고 밝혔다. 이 배수는 어디서 올까? 아래 실험에서 한 번의 요청이 쓰는 토큰을 항목별로 쌓아 보자. 모든 모델 호출은 그때까지의 입력 전체를 다시 읽는다는 점(3장의 누적)이 핵심이다.

에이전트를 늘리면 얼마나 빨라지나

3장의 임계 경로는 작업 하나의 한계였다. 시스템 전체의 처리량에도 한계가 있다. Neil Gunther의 범용 확장성 법칙Universal Scalability Law은 작업자 수 n을 늘릴 때 처리량이 두 가지 이유로 꺾인다고 본다. 하나는 경합 σ: 공유 자원(리더, API 한도, 공유 상태의 잠금)을 기다리는 시간. 다른 하나는 일관성 비용 κ: 작업자끼리 서로의 상태를 맞추는 비용으로, 쌍의 수 n(n−1)에 비례한다. κ가 0보다 크면 어느 지점부터 에이전트를 늘릴수록 오히려 느려진다.

X(n) = n1 + σ(n − 1) + κ n(n − 1)   ·   n* = √(1 − σ) / κ
σ = κ = 0이면 선형, κ = 0이면 암달의 법칙과 같은 모양(천장 1/σ). 멀티에이전트에서 κ는 메시 토론이나 공유 문서 동기화처럼 모두가 모두의 상태를 알아야 하는 구조에서 커진다(2장의 n(n−1)/2 채널).

역할마다 다른 모델

모든 에이전트가 같은 모델일 필요는 없다. 계획과 합성처럼 판단이 어려운 일은 큰 모델에, 정해진 형식으로 자료를 모으는 일은 작고 빠른 모델에 맡길 수 있다. 이것이 모델 계층화model tiering다. 앞의 Anthropic 사례도 리더에는 상위 모델을, 하위 에이전트에는 그보다 가벼운 모델을 썼다고 설명한다. 아래 실험의 단가와 품질은 상대값이다.

정해진 예산을 몇 명에게

예산이 정해져 있으면 질문이 바뀐다. 토큰 100만 개로 워커 2명이 깊게 팔 것인가, 20명이 얕게 훑을 것인가? 조사할 방향들의 중요도는 고르지 않아서, 상위 몇 개가 대부분의 가치를 가진다. 워커를 늘리면 더 많은 방향을 덮지만 각자 쓸 토큰이 줄고, 워커마다 드는 고정 비용(시작 프롬프트, 지시서, 합성)이 예산을 갉아먹는다.

가치(n) = Σi=1..n wi · (1 − e−b/τ),   b = B − n · On
wi: 중요도 순으로 줄 세운 방향 i의 가치(지프 분포), B: 전체 예산, O: 워커 하나의 고정 비용, τ: 방향 하나를 충분히 파는 데 필요한 토큰의 척도.

핵심 정리

  1. 멀티에이전트의 토큰은 에이전트마다 반복되는 시스템 프롬프트, 지시서, 누적된 도구 결과, 요약과 합성에서 나온다. 캐시와 짧은 고정부가 배수를 줄인다.
  2. 경합 σ는 처리량에 천장을, 일관성 비용 κ는 꺾임점 n* = √((1−σ)/κ)를 만든다. 모두가 모두를 알아야 하는 구조일수록 일찍 꺾인다.
  3. 판단이 어려운 리더에는 큰 모델, 정형화된 워커에는 작은 모델. 워커 일이 어려우면 워커 모델을 아끼지 않는다.
  4. 정해진 예산에서는 중요도 쏠림, 워커 고정 비용, 방향당 필요한 깊이가 최적 워커 수를 정한다.

확인 퀴즈

1. 멀티에이전트 시스템의 토큰 중 가장 큰 몫이 되기 쉬운 것은?

모델은 매 호출 입력 전체를 다시 읽는다. 호출이 많고 결과가 길수록 누적이 커진다.

2. σ = 0.04, κ = 0.0024일 때 처리량이 가장 높은 에이전트 수는 대략?

√((1 − 0.04) / 0.0024) = √400 = 20.

3. 정해진 형식으로 공시 자료에서 숫자만 뽑는 워커 20명. 비용을 줄이려면?

비용은 워커 수만큼 곱해지고, 일이 정형화되어 있으면 작은 모델로 충분하다. 리더의 판단 품질은 지킨다.

4. 같은 예산에서 최적 워커 수를 줄이는 요인은?

고정 비용은 워커 수에 비례해 예산을 먹고, 쏠림이 크면 덜 중요한 방향을 덮는 이득이 작다.
