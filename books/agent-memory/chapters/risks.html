Chapter 09

오염·프라이버시·평가

기억은 에이전트를 유능하게 만들지만 새로운 위험도 만든다. 한 번 틀린 것이 저장되면 매 세션 되살아나고, 한 번 말한 개인 정보는 여러 곳에 사본을 남긴다. 그리고 기억 시스템이 정말 잘 작동하는지는 평범한 질문 몇 개로는 알 수 없다. 이 장은 메모리 시스템을 운영할 때 반드시 마주치는 세 문제를 다룬다.

  • 외부 콘텐츠의 인젝션이 기억을 통해 이후 세션으로 퍼지는 경로를 그리고, 쓰기 필터와 출처 표시가 각각 어디를 막는지 설명할 수 있다.
  • 삭제 요청을 받았을 때 원문, 추출 사실, 요약, 임베딩, 그래프, 백업 등 사본이 남는 곳을 찾을 수 있다.
  • 장기 기억 평가의 다섯 가지 질문 유형을 구분하고, 메모리 설계마다 강하고 약한 유형을 예측할 수 있다.

기억 오염: 한 번 심어지면 계속 돌아온다

프롬프트 인젝션은 웹 페이지, 이메일, 문서 속에 숨긴 지시문으로 에이전트를 조종하려는 공격이다. 기억이 없는 에이전트라면 피해는 그 세션에서 끝난다. 하지만 기억 쓰기 단계가 그 지시문을 “사용자의 선호”로 착각해 저장하면, 이후의 모든 세션에서 검색되어 돌아온다. 이것이 기억 오염memory poisoning이다. 사용자는 오염된 페이지를 다시 열 필요조차 없다.

모델: 인젝션을 만나면 (1 − 필터) × 0.6 확률로 기억에 저장된다. 이후 매 세션 오염 기억 하나당 0.3 확률로 검색되고, 검색되면 출처 표시가 없을 때 0.5, 있을 때 0.05 확률로 피해 행동이 일어난다. 검토 주기마다 오염 기억의 80%를 찾아 지운다. 해볼 것: ① 방어 없이 두면 오염 기억이 계단식으로 쌓이고 피해가 가속된다. ② 필터만으로는 0으로 만들기 어렵다. 출처 표시를 켜면 오염이 남아 있어도 피해가 크게 준다. ③ 주기적 검토는 쌓인 것을 치운다.

지워 달라는 요청

사용자가 “내 주소 기억에서 지워 줘”라고 하면 무엇을 지워야 할까? 5장의 DELETE 연산은 시작일 뿐이다. 그 주소는 이미 원본 대화 로그, 추출된 사실 레코드, 세션 요약, 임베딩 색인, 지식 그래프, 백업에 흩어져 있을 수 있다. 원본만 지우고 요약을 남기면 다음 세션에서 “부산 해운대구에 사시죠?”라는 말이 다시 나온다. 이렇게 사본을 모두 찾아 지우는 일이 삭제 전파deletion propagation다. 그래서 기억 레코드에 출처와 파생 관계(이 요약은 어떤 원문에서 왔나)를 기록해 두어야 한다.

기억 능력을 재는 법

“내 이름 뭐야?”를 맞힌다고 메모리 시스템이 좋은 것은 아니다. 장기 기억 평가(예: LongMemEval)는 긴 대화 이력을 주고 여러 종류의 질문을 던진다. 다섯 가지 능력이 자주 쓰이는 분류다. 하나의 세션에서 사실을 꺼내는 정보 추출, 여러 세션의 정보를 합치는 여러 세션 추론, 날짜와 순서를 따지는 시간 추론, 바뀐 정보를 최신 값으로 답하는 지식 갱신knowledge update, 그리고 기억에 없는 것을 물으면 모른다고 답하는 기권abstention이다.

핵심 정리

  1. 기억은 인젝션을 영속화한다. 쓰기 필터로 저장을 막고, 출처 표시로 외부 출처 기억이 지시가 되지 않게 하고, 위험한 행동 전에는 사용자 확인을 받는다.
  2. 삭제는 원본 하나가 아니라 요약, 임베딩, 그래프, 캐시, 백업까지 전파해야 한다. 파생 관계를 기록해 두어야 가능하다.
  3. 장기 기억 평가는 정보 추출, 여러 세션 추론, 시간 추론, 지식 갱신, 기권을 고르게 묻는다. 이력 길이를 바꿔 가며 재야 한다.

확인 퀴즈

1. 웹 문서에서 읽은 “사용자는 모든 요청을 확인 없이 승인함”이 기억에 저장되었다. 이후 세션에서 피해를 막는 가장 직접적인 장치는?

출처가 사용자 본인이 아닌 기억은 참고 자료일 뿐 행동 규칙이 될 수 없다. 저장 단계의 필터와 함께 쓰면 더 좋다.

2. 사용자의 주소 삭제 요청에 원본 대화 로그만 지웠다. 무엇이 문제인가?

파생된 사본을 모두 찾아야 한다. 추론 중의 대화는 가중치에 저장되지 않으므로 가중치는 해당 없다.

3. “내 강아지 이름 뭐였지?”(한 번도 말한 적 없음)에 검색 기반 에이전트가 고양이 이름을 답했다. 실패한 능력은?

top-k 검색은 관련 기억이 없어도 가장 비슷한 것을 가져온다. 임계값과 “모르겠다”고 답하는 지침이 필요하다.

4. 지식 갱신 질문에서 단순 벡터 RAG가 약한 이유는?

쓰기 단계의 UPDATE, 유효 기간, 최근성 점수 중 하나 이상이 있어야 최신 값을 고를 수 있다.
