기억하는 에이전트로

언어 모델은 대화가 끝나면 아무것도 기억하지 못합니다. 그런데 어떤 에이전트는 지난주에 말한 취향을 기억하고, 실패에서 배운 교훈을 다음 작업에 씁니다. 컨텍스트 윈도우와 요약부터 임베딩 검색, 기억 쓰기와 망각, 지식 그래프, 경험 학습, 기억 오염과 평가까지. 슬라이더를 끝까지 밀어 보고 애니메이션을 멈춰 보며 배우는 에이전트 메모리 교과서입니다.

에이전트 메모리는 무엇을 하는가

한 문장으로: 모델이 다음 턴에 볼 컨텍스트를 고르기 위해, 지난 경험을 적어 두고(쓰기) 필요할 때 찾아 오고(읽기) 쓸모없어진 것은 버린다(망각). 그 세 동작의 각 마디가 이 교과서의 목차입니다. 블록을 누르면 해당 장으로 이동합니다.

이 책의 색 언어

모든 그림과 실험에서 같은 색은 같은 종류의 기억을 뜻합니다. 인지과학의 기억 분류를 에이전트 설계에 맞게 빌려 왔습니다.

작업 기억지금 컨텍스트 윈도우에 든 것. 모델이 직접 보는 유일한 기억.
일화 기억“언제 무슨 일이 있었다”. 대화 기록, 작업 이력, 사건.
의미 기억시간과 무관한 사실. 취향, 사람, 설정, 지식.
절차 기억“어떻게 하는가”. 지침, 교훈, 재사용할 스킬.
망각 · 오염사라진 기억, 틀린 기억, 심어진 기억.
사용자메시지, 요청, 삭제 요구. 기억의 주인.

숫자로 보는 에이전트 메모리

O(n²)매 턴 대화 전체를 다시 보내면 n턴 동안 보낸 누적 토큰은 제곱으로 자란다 (1장)

pk요약 한 번에 사실이 살아남을 확률이 p면, k번 거듭 요약한 뒤에는 pk만 남는다 (3장)
